Integrated local session management
The session_manager modules were supplied by the user from the local
CodexSessionManager v1.1.1 project. Its original project remains unchanged.
SessionBackend.exe bundles the Python runtime and the psutil and zstandard
packages. It is built with PyInstaller (bootloader exception applies).

application releases and session-backend/licenses/ in this source project.
