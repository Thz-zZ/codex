# Codex 本地会话管理器

中文 Windows 桌面工具，查看当前用户的本地 Codex 会话，预览对话，支持单个和批量永久删除。

## 使用

1. 双击 `CodexSessionManager-v1.1.1.exe`。无需安装 Python；电脑上需要有 Codex 才能调用官方删除接口。
2. 程序自动读取 `CODEX_HOME`，未设置则读取 `%USERPROFILE%\.codex`。在“设置”中可以更换数据目录和 `codex.exe`。
3. 搜索标题、项目路径或会话 ID，筛选全部、普通、已归档会话。点击一行查看右侧“用户 / AI · Codex”对话卡片和消息时间。默认隐藏工具调用；勾选“显示工具详情”后可展开查看。长对话点击“加载后续内容”。预览为纯文本，附件只显示提示；来源没有时间戳的消息不显示时间。
4. 勾选复选框后点击“删除已选”，或者在右侧点击“删除此会话”。“全选筛选结果”包含当前筛选中的所有行，包括屏幕外的行。更改搜索或筛选会清空已选项。
5. **删除前请关闭 Codex 桌面应用，以及 VS Code 中的 Codex 扩展/终端。** 其他 Codex 进程仍在运行时，本软件无法确认会话是否被占用，会暂停删除；不会自动关闭或终止这些进程。
6. 核对确认框中的完整列表，包含连带删除的派生子会话。勾选确认后点击“永久删除”。**不备份、不可恢复。** 项目代码和工作目录不在本软件删除范围内。

## 读取和兼容性

- 合并只读数据库索引、旧版 JSONL 文件和官方列表接口，以会话 ID 去重；同时覆盖普通、归档和子会话。
- “读取详情”显示每个来源的数量。文件数和会话数不一定相同：新版会话可仅存在于数据库中，部分旧文件可能没有数据库索引。
- 标注“内容缺失”的会话仍可显示索引，无法凭空恢复对话内容。
- 对话优先通过官方分页接口读取，无法读取时使用本地数据库或文件的只读适配器。新版日志可能比数据库投影更新，此时合并数据库前缀与日志里的完成消息，按消息 ID 去重，避免漏掉近期问答。
- 会话内容使用 Codex 官方 `thread/delete` 删除；核实内容消失后，按同一会话 ID 清理 `sqlite/codex-dev.db` 中 `local_thread_catalog` 的本地目录记录并更新目录版本。保留其他会话、远程主机记录及其他表。目录结构不兼容时先阻止删除；清理失败时明确报告，不宣称全部成功。
- 检测外部 Codex 进程采用保守策略；其他数据目录的 Codex 进程也会暂停删除。关闭客户端后直接重试即可。
- 批量删除不是事务：成功项不会回滚，失败项会列出原因。重新刷新后可以只重试仍存在的项。
- v1.1.1 对当前待删子树深查内容，复用未变化文件的元数据，每次重新检查目录、文件状态和数据库；批次结束时集中清理成功删除项的桌面目录。仍检查新子会话、内容变化和客户端占用。
- 本工具不管理远程、云端会话或其他 Windows 用户的数据，不发送模型请求。Codex 本地服务可能按自身正常运行方式更新日志、缓存或元数据。
- 已验证环境：Windows x64，Codex CLI `0.154.0-alpha.6.2`，`state_5.sqlite` 与 `thread_history_1.sqlite`。
- “永久删除”指官方接口删除逻辑记录及关联历史，不是对磁盘剩余空间作取证级擦除。

## 批量导出与导入（1.1.0）

勾选左侧会话，点击“导出已选”，保存为 ZIP 包。选择“全选筛选结果”可导出当前筛选下的全部会话。导出期间如果检测到所选会话变化，会停止并提示重试，不覆盖上次导出文件。

点击顶部“导入会话”并选择本软件导出的 ZIP 包，查看包内会话及数量，再执行导入。一个包可以包含多个会话。已有相同 ID 的会话会跳过，不覆盖或合并；需要恢复缺失内容的已有会话时，请先自行核对现有数据。

导入前关闭 Codex 桌面应用和其他 Codex 客户端。导入通过校验后的本地数据恢复实现，不调用不存在的官方导入接口；要求目标数据库已初始化且与来源存储结构一致。来源不兼容时会阻止导入。成功后刷新本软件或重新打开 Codex 即可查看。

导出包括所选会话的原始会话文件、数据库对话及必要会话元数据；保留会话 ID、标题、时间、归档和所选会话之间的父子关系。原始文件名保持不变，以保留新版历史关联。如果派生会话依赖未选中的源会话，会提示一并选择来源。不会导出账户认证、全局配置或整个数据目录。

跨机器导入保留原项目路径，不复制项目代码、工作目录和外部附件。侧栏分组、项目 ID 和置顶状态不迁移。继续对话需要目标机器有相应项目，且本机 Codex/provider 配置可用。原来已缺失的源文件无法凭导出恢复。

支持本软件 ZIP 格式，不支持任意聊天 JSON/Markdown 文件导入。单个原始文件最多 512 MiB，单个会话结构化数据最多 128 MiB，解压数据总量最多 4 GiB；超过时请减少选择数量。导入包逐项校验哈希和目标路径，不执行包中的脚本或 SQL。每个会话作为一个数据库事务写入；失败会停止后续导入并报告，之前成功的会话保留。

官方接口文档：https://developers.openai.com/codex/app-server

## 从源码运行和打包

需要 Python 3.13 x64。安装和构建命令在源码目录执行：

```powershell
py -3.13 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe main.py
.venv\Scripts\python.exe -m pytest tests -q
.venv\Scripts\python.exe build.py
```

程序输出到 `dist\CodexSessionManager.exe`。可用 `--output` 指定输出目录，`--work` 指定打包临时目录。

命令行可选参数：`--home <数据目录>`、`--codex <codex.exe 路径>`、`--read-only`。

## 测试说明

测试仅在 pytest 的隔离临时目录创建虚构会话。真实会话仅作只读核对。
包含列表合并、中文搜索、批量选择、分页、取消确认、范围变化、占用保护、部分失败及官方删除接口集成测试。
`tests/history_schema.sql` 仅含本机 Codex 版本的表结构与迁移元数据，不含任何用户会话或认证信息，用于新版历史数据库的集成测试。
