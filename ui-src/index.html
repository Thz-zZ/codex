统一使用中转提供的自动提示词缓存，不注入模型专用缓存字段，不在本机缓存完整回答或工具结果。

命中可能降低重复输入的费用和延迟，不减少输出 Token；实际支持与优惠由中转决定，不保证命中。需要专用标记的服务可能无法命中。

真实缓存读取、写入及命中率请查看各中转的用量统计。保持模型、工具定义和重复前缀稳定，有助于复用。

统计口径

缓存率 = 缓存读取 Token ÷ 总输入 Token。输出不计入分母，缓存写入不算命中。

NewAPI 返回近期日志，历史可能受条数限制。Sub2API 返回最多近 90 天的模型和每日汇总，不能展示逐条请求或请求命中率。

账户余额只读取账户字段。接口未开放时显示原因，不使用密钥剩余额度代替。
